# InsurCraft 2.0 — "Fácil"

Copia de trabajo separada de InsurCraft 1.x (repo `Pourider/insurcraft`), sin conexión a GitHub.

Objetivo: mismas funciones, interfaz pensada para gente que no lee mucho.

- Botones grandes con ícono y una sola palabra.
- Un color fijo por función: Unir azul, Separar naranja, Ordenar morado, Firmar verde, Poner clave negro, Achicar mostaza.
- Palabras simples: Achicar (comprimir), Tapar datos (redactar), Poner clave (proteger), Llenar (formulario).
- Cada tarea en pasos numerados (1 Agrega → 2 Ordena → 3 Guarda) con un solo botón verde para terminar.
- Pantalla final "¡Listo!" con Ver y Carpeta.
- Funciones menos usadas en la fila "Más".

Las pantallas de referencia están en esta carpeta (`*.dc.html`): Main (inicio), Unir, Firmar, Listo.
